<METHOD />

Primeiro eu crio uma ponte. Depois a gente encara o código real.

Quando um conceito parece abstrato demais, eu começo por uma comparação simples. Não para infantilizar o assunto, mas para dar uma imagem mental antes de entrar na explicação técnica e no projeto funcionando.

<EXTENSIONS.PY />

extensions.py como a caixa de ferramentas do projeto.

Foi assim que essa parte fez sentido para mim: uma caixa onde ficam ferramentas importantes da aplicação. Depois a gente tira a analogia da frente e olha para o arquivo extensions.py como ele é: banco, proteção e autenticação preparados para o projeto Flask.

A analogia é só a ponte inicial. O destino continua sendo entender o conceito e escrever o código real.

CAIXA DE FERRAMENTAS extensions.py
db

A ferramenta utilizada para trabalhar com o banco de dados.

csrf

Uma ferramenta responsável por adicionar proteção CSRF à aplicação.

login_manager

A ferramenta utilizada para gerenciar a autenticação com Flask-Login.

CAIXA DE FERRAMENTAS extensions.py CÓDIGO REAL 
from flask_sqlalchemy import SQLAlchemy
from flask_login import LoginManager
from flask_wtf.csrf import CSRFProtect

db = SQLAlchemy()
login_manager = LoginManager()
csrf = CSRFProtect()
